# Marvel United: Comic-Accurate Campaign Suggestions

All character pairings in this file are validated against the [comic-accuracy tool](https://github.com/kuarahy/Marvel-United-Randomizer/tree/main/tools/comic-accuracy) (co-appearance data, 1961–2002). Every pairing listed has **≥ 20 shared comic issues**. Scores shown are from `co-appearances.json`.

> **Threshold guide:** > 100 = core relationship · 20–100 = solid shared history
